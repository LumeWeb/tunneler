Readiness is now a hybrid: the cloudflared CONNECTED signal establishes the edge connection (deterministic, no startup race), then a bounded edge-aware probe of the public URL (`probeOriginReady`, 10s budget via `cloudflaredProbeTimeout`, ~300ms retry interval) must confirm a genuine origin response. The pure `isGenuineOriginResponse` classifier accepts only 2xx-4xx responses that are neither challenge pages (`cf-mitigated: challenge`) nor Cloudflare edge error pages (`cf-error-type`/`cf-error-origin` set), so the WAF-403 false-negative fix is preserved while end-to-end deliverability (DNS/CNAME route present, origin reachable) is verified again. Regression tests added: `TestCloudflaredStartFailsWhenProbeDoesNotConfirmReachability` and the `TestIsGenuineOriginResponse` table (which fails under a naive <500 rule), all green under `-race -count=1`.
